Locate and Launch support

Search your text. Select a result. Run an action.

Locate and Launch lets you search text or delimited files and use matching results with links, apps, and Apple Shortcuts.

Need help or found a problem?

Report an issue or request a feature on GitHub. Include your app version, iOS version, what you expected to happen, and what happened instead.

Get support on GitHub

GitHub issues are public. Do not include passwords, access keys, private files, or other sensitive information.

Getting started

  1. Add a source from a file, a URL, or the examples catalog.
  2. For delimited files, choose the fields to use for the key and search text. A label is optional.
  3. Search for the text you need and select a result.
  4. Choose an action to open a link, run a Shortcut, or use the selected text.

Using actions

Action templates can use {key}, {label}, {line}, and {linenum} to pass values from a selected result. For a Shortcut, make sure the name in your action matches the installed Shortcut.

A source will not load

Check that the file is available and the URL is reachable. For a remote source, confirm that your network connection and any required credentials are working. Check the delimiter and selected fields when importing a delimited file.

An action does not work

Check the URL template and the values supplied by your source. Make sure the destination app or Shortcut is installed. If the action calls a server, check its address and authentication settings.

Your privacy

Locate and Launch does not collect personal information. Read the privacy policy for details about local data and services you choose to use.
